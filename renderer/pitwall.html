Race

Set a start time in the future and every screen counts down to it; the race clock and all stints start automatically at that moment. START RACE in the top bar always starts the clock immediately instead. While the timing feed is connected, the session length follows the feed and the race clock starts by itself when the feed's session goes live — the values set here only apply without a feed. SYNC FROM LIVE TIMING aligns elapsed/remaining once with the feed's session clock; "keep locked" re-aligns continuously (the clock freezes with the official clock under red flags).

Car names

The name each car shows on every screen and in the car pickers (the start screen and each station's CONNECTION tab). Leave a name empty to go back to the default "Car #<number>". The race number, make and model are set on each car's own station (SETTINGS → CAR), and a station can rename its own car there too — last edit wins.

Event settings — shared by all cars

Pit arrival estimate — track geometry

Track properties and event regulations that are the same for every car: they are set once here and pushed to all four cars immediately — the car stations show them read-only. Car-specific values (tank, burn rates, lap times, tyre & brake life, tyre-change time) stay on each station. Pit lane length ÷ speed limit gives the time spent driving the lane; the pit lane loss on top of that is the entry/exit braking and the detour versus staying on track. The sector distances place a car on track by the sector it last completed (the wall's PIT ENTRY countdown); with the pit entry point set, the countdown runs to the actual entry instead of the S/F line. 0 on any distance falls back to the timing feed's own loop positions. The countdown formula: position now = last S1/S2/S3 crossing + green speed × time up to the flag + FCY/SC speed × time since the flag; time to pit entry = distance left to the entry ÷ current speed; time at box = that + (pit lane length ÷ 2) ÷ pit lane speed limit. Green speed is the car's own live average lap (car-specific); the FCY and Safety-Car speeds are the event settings above.

A race setup stores the race name, duration and all event settings on this pit wall PC (car names travel with the cars themselves, not the setup). Prepare the real event during a test or practice session, save it, and load it back when the race weekend starts: LOAD applies the values immediately on every screen. Live timing feed

Feed off.

The connection is made from this pit wall PC only; every station receives the decoded standings automatically, including feed errors and reconnect status. The URL source works with getraceresults and Al Kamel public pages; the direct connector is the paid Time Service TeamStream feed — the key comes from the timekeeper. Standard ports: 12921 plain / 12922 SSL (getraceresults.com uses 12961 / 12962). For known ports the plain-vs-SSL choice is applied automatically, whatever the checkbox says. The flag check URL is the event's public getraceresults page: its explicit flag state (the coloured box on the website) is the only source of safety car / FCY / Code 60 / red on a direct TeamStream connection — the direct feed carries no flag element, and race-control messages are shown as text but never change the flag. Without it the flag only shows green (running) and finish from the session clock. Connecting via the URL source instead of the direct feed carries the board flag already.

Car links

Each car follows the timing entry with its own race number unless a different number is set here. AUTO is on by default: completed laps (and pit in/out) from the feed drive that car's lap counter, tyre wear and pit state — the station's manual lap logging hides while the feed is live and returns if it drops. Turn AUTO off to keep a car on manual lap logging. AUTO only counts laps while the race clock runs.
