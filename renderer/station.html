CAR SETTINGS

Car information

Fuel consumption model

Per-driver average uses each driver's dry/wet L/lap from the DRIVERS tab (0 = car default below). Per lap time reads each driver's lap time → L/lap table on the DRIVERS tab and interpolates between the measured points, using the rolling average of the last laps from live timing. Outside the measured range the nearest value is held flat rather than extrapolated. A driver with no points falls back to their average, then to the car default. What the model is doing right now is shown live in the fuel panel on the main screen.

Learned from live data

While the race runs, every representative green lap teaches the model each driver's real pace, and every trusted fuel figure (a SET correction or a refuel to a planned level) closes the laps since the previous one into a real consumption sample. ADOPT writes the learned figure into the driver table (or adds a curve point when the per-lap-time model is active) — the projections use it immediately.

Fuel & lap model (car defaults)

Safety Car and FCY / Code 60 have separate rates: behind the Safety Car the field still circulates at a fair pace, while FCY / Code 60 holds a fixed delta speed, so the lap is slower but leaner. When the timing feed reports either one, every car switches to the matching rate automatically. While the race clock runs, the tank drains continuously at the active burn rate (per-driver, or the neutralisation rate when one is in force) — laps only count tyre wear. The drain pauses while the car is marked IN PIT LANE, and a completed stop resets the tank to the stop's fuel level. Use SET in the fuel panel to correct to a real reading. Finish margin = fuel still wanted at the flag; safety level = fuel the tank must never drop below — all window and refuel calculations run on the fuel above safety.

Degradation & limits

Tyre life is a distance: —. Change the track length (event settings) and the lap figure follows. The maximum stint length is an event setting — see the event settings below.

Tyre sets

Every set the car has for the race, by name. The set on the car accrues the laps counter above and banks its mileage lap by lap (track length per lap, with the part driven under a neutralisation counted separately). A stop with TYRES moves the wear into the outgoing set and fits the chosen one (FIT SET in the stop planner — default: the next new set); the set that comes off then asks to be kept or scrapped. Refitting a used set starts it pre-worn with its recorded laps. SCRAP takes a set out of the pool for good — it disappears from FIT SET and the app will never choose it — until RESTORE brings it back. "Tyre sets available" above and this list stay in sync.

Brake sets

The rack, by part number. Front discs are one numbered pair and rear discs another, and so are the front and rear pads — each is one line here and one line on the stop card. Type the number that is written on the part; the hours counter above belongs to whichever set is on the car. A stop that changes a component banks its hours into the outgoing set and fits the chosen one (SELECT PARTS… in the stop planner — default: the next unused set). Refitting a used set starts it pre-worn with its recorded hours. SCRAP takes a set out of the rack for good — the app will never choose it — until RESTORE brings it back. The counts above and this list stay in sync.

Pit stop timing

Estimated stationary time = fuel ÷ refuel pump speed + tyre change, assumed sequential (no other work while fuel flows). Shown live in the stop planner and on the pit wall.

Event settings (set on the pit wall)

Track length, FCY speed, pit lane loss, refuel pump speed and max stint are the same for every car — the pit wall's RACE SETTINGS → RACE tab is the only place to change them. The FCY pit-gain figures live on the main screen next to the timeline.

Race start

Fuel on board when the race starts — leave empty (or 0) to start on a full tank. Before the start the gauge follows this figure; a RESET RACE puts the car back on it. The starting driver is the one credited with the first stint's seat time.

Fuel 0 = use the car default burn rate. While a driver is in the car, their own dry/wet consumption drives the fuel projections and the pit-window maths. Abbr is the short driver code shown in compact readouts (empty = derived from the name). Timing name is the driver's name exactly as the live timing feed prints it — it lets every screen recognise who is in the car from the feed (a surname is enough; empty = match on the driver's name).

Fuel vs lap time

One table per driver: a lap time and the fuel burned on a lap at that pace. Consumption between two rows is interpolated linearly, so two or three honest points (a push lap, a cruise lap, a fuel-save lap) are enough. These tables are only used when the FUEL tab's model is set to per lap time.

Setup presets

A preset stores this car's full setup — car info, fuel & lap model, wear, pit timing and the driver table. Presets are kept on the pit wall PC, so every station sees the same list and can load one instantly.

Pit wall connection

Status—

This station connects to the pit wall PC whose address is shown above — it is set on the start screen and remembered on this PC; it never switches to another server by itself. The pit wall screen shows the address stations must use (use 127.0.0.1 to run a station on the pit wall PC itself, e.g. for testing). The port is 8484 unless the pit wall says otherwise. APPLY stores the new address and reconnects this station immediately.

Theme

Track location — for the auto switch

AUTO switches to dark 30 min before sunset and back to light 1 h after sunrise, computed from the sun times at this location (default: Circuit Zolder). The theme choice is saved on this PC only — each screen picks its own.

STINT PLAN

Plan timeline

The plan is built for THIS timeline, not necessarily the running session — so a full 24 h race plan can be prepared while a 30-minute practice session is on. Both fields prefill from the current session; change them to plan a different race. The start time drives which stints count as night.

Built from the DRIVERS table: stint length = min(max stint, full tank at the driver's dry burn); night stints (21:00–06:00) only go to night-capable drivers; double-stint drivers run two stints back-to-back; seat time is balanced across the crew. Regenerate after changing driver settings, or REPLAN to rebuild only the remainder around what has actually been driven (REPLAN always follows the live session clock, not the timeline above).
