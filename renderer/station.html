CAR SETTINGS

No pit wall — these pages are filling in a CAR FILE on this PC. Everything here (car, fuel, pace, wear, drivers, tyre and brake sets) is saved on this machine only: nothing is sent to a car. Build the setup, save it under CAR FILE, and load that file onto the car once the pit wall is up. Connect a station (CONNECTION tab) and these pages switch to the real car.

Car information

Fuel consumption model

Per-driver average uses each driver's dry/wet L/lap from the DRIVERS tab (0 = car default below). Per lap time reads each driver's lap time → L/lap table on the DRIVERS tab and interpolates between the measured points, using the rolling average of the last laps from live timing. Outside the measured range the nearest value is held flat rather than extrapolated. A driver with no points falls back to their average, then to the car default. What the model is doing right now is shown live in the fuel panel on the main screen.

Learned from live data

While the race runs, every representative green lap teaches the model each driver's real pace, and every trusted fuel figure (a SET correction or a refuel to a planned level) closes the laps since the previous one into a real consumption sample. ADOPT writes the learned figure into the driver table (or adds a curve point when the per-lap-time model is active) — the projections use it immediately.

Fuel & lap model (car defaults)

Safety Car and FCY / Code 60 have separate rates: behind the Safety Car the field still circulates at a fair pace, while FCY / Code 60 holds a fixed delta speed, so the lap is slower but leaner. When the timing feed reports either one, every car switches to the matching rate automatically. While the race clock runs, the tank drains continuously at the active burn rate (per-driver, or the neutralisation rate when one is in force) — laps only count tyre wear. The drain pauses while the car is marked IN PIT LANE, and a completed stop resets the tank to the stop's fuel level. Use SET in the fuel panel to correct to a real reading. Finish margin = fuel still wanted at the flag; safety level = fuel the tank must never drop below — all window and refuel calculations run on the fuel above safety.

Tyre sets

The set list arrives with the pit wall link.

Every set the car has for the race, by name. GENERATE SETS… writes the whole allocation in one go: a naming pattern ([#] is where the number goes, [###] pads it to 001), a starting number and a count — so the list reads the way the stickers on the rubber do. REPLACE UNUSED swaps out the sets nobody has run yet; the set on the car, every used set and every scrapped one stay, mileage and all. The set on the car accrues the laps counter above and banks its mileage lap by lap (track length per lap, with the part driven under a neutralisation counted separately). A stop with TYRES moves the wear into the outgoing set and fits the chosen one (FIT SET in the stop planner — default: the next new set); the set that comes off then asks to be kept or scrapped. Refitting a used set starts it pre-worn with its recorded laps. Rubber that arrives with mileage on it — a test day, a set bought used — is typed straight into the laps and km boxes; km is what tyre life is measured against, so a set with laps but no kilometres still reads as good for a full life. Both back to zero and the set is new again. SCRAP takes a set out of the pool for good — it disappears from FIT SET and the app will never choose it — until RESTORE brings it back. "Tyre sets available" above and this list stay in sync.

Brake rack

The rack reads like the car: front on the left, rear on the right, one box per kit. Pads are bedded onto discs: a pad set bedded onto a disc set is a kit, and a kit is what the car runs and what a stop calls for by name (F1, R2…). Bed a set on with BED PADS on the head of a disc box, or open a free pad set and use BED ONTO. Each line is a part — its number, its hours and the bar of life it has left; click a line to change the number written on it, correct its wear — as hours run or as the percent left a gauge reads, either box writes the other — scrap it or take it off the rack. The part on the car takes a correction too: the live counter picks up the typed figure and ticks on from it. What comes out of the box is always a kit — fit pads onto the discs already on the car and the rack re-ties itself to match.

The rack arrives with the pit wall link.

The rack, by part number. GENERATE SETS… writes whole pools at once: tick the component groups, then give a naming pattern, a starting number and a count — [P] is that group's own prefix (PF, PR, DF, DR), [#] is the number and [###] pads it, so [P][#] makes PF1… and DR1… in one pass. The starting number continues the series already on the rack, and REPLACE UNUSED swaps out the sets nobody has run — the set on the car, every used set and every scrapped one stay, hours and all. Front discs are one numbered pair and rear discs another, and so are the front and rear pads — each is one line here and one line on the stop card. Type the number that is written on the part; the hours counter above belongs to whichever set is on the car. A stop that changes a component banks its hours into the outgoing set and fits the chosen one (SELECT PARTS… in the stop planner — default: the next unused set). Refitting a used set starts it pre-worn with its recorded hours. SCRAP takes a set out of the rack for good — the app will never choose it — until RESTORE brings it back. The counts above and this list stay in sync.

Pit stop timing

Estimated stationary time = fuel ÷ refuel pump speed + tyre change, assumed sequential (no other work while fuel flows). Shown live in the stop planner and on the pit wall.

Event settings (set on the pit wall)

Track length, FCY speed, pit lane loss, refuel pump speed and max stint are the same for every car — the pit wall's RACE SETTINGS → RACE tab is the only place to change them. The FCY pit-gain figures live on the main screen next to the timeline.

Race start

Fuel on board when the race starts — leave empty (or 0) to start on a full tank. Before the start the gauge follows this figure; a RESET RACE puts the car back on it. The starting driver is the one credited with the first stint's seat time.

Fuel 0 = use the car default burn rate. While a driver is in the car, their own dry/wet consumption drives the fuel projections and the pit-window maths. Abbr is the short driver code shown in compact readouts (empty = derived from the name). Timing name is the driver's name exactly as the live timing feed prints it — it lets every screen recognise who is in the car from the feed (a surname is enough; empty = match on the driver's name).

Fuel vs lap time

One table per driver: a lap time and the fuel burned on a lap at that pace. Consumption between two rows is interpolated linearly, so two or three honest points (a push lap, a cruise lap, a fuel-save lap) are enough. These tables are only used when the FUEL tab's model is set to per lap time.

Car file

A car file is one JSON file holding everything that belongs to this car — name, number, make and model, the fuel model and tank, burn rates and average laps per condition, finish margin and safety fuel, tyre and brake life, tyre-change time, the whole driver table (including the fuel-vs-lap-time curves) and the tyre and brake racks by name. What it deliberately does not hold is the event: track length, pit lane, refuelling rig and drive-time regulations are the same for every car and are set once on the pit wall — that is the line the file draws between the two kinds of setting. Loading one never touches race data: laps, mileage, banked hours, seat time and every set that has already run stay exactly as they are, so a file can be loaded mid-race to correct a figure. Prepare the four files at home with no pit wall running at all, keep them with the car, and each station is set up in one click.

Setup presets

A preset stores this car's full setup — car info, fuel & lap model, wear, pit timing and the driver table. Presets are kept on the pit wall PC, so every station sees the same list and can load one instantly.

Page size — how large this station draws itself

100%

The strategy view carries every figure for the car at once, and it used to be shrunk until all of it fitted the window whatever that did to the type — 77% on a 1920×1080 screen, 62% on a 1600×900 laptop, which puts the small labels under 9 px. It now stops at 90%, and whatever is left over scrolls in the columns; the flag bar, the race-control strip, the banners and the NOW row stay put, and the stop card on the right scrolls on its own, so it is never pushed off by the left column. AUTO also enlarges the page on a screen with room to spare, which the old ceiling of 100% refused to do — a 4K panel was being handed the same design in smaller millimetres. Drag until it reads from where you sit; drag down if you would rather have the whole page on screen than a larger one. Saved on this PC only, like the theme.

Theme

Track location — for the auto switch

AUTO switches to dark 30 min before sunset and back to light 1 h after sunrise, computed from the sun times at this location (default: Circuit Zolder). The theme choice is saved on this PC only — each screen picks its own.

STINT PLAN

Plan timeline

The plan is built for THIS timeline, not necessarily the running session — so a full 24 h race plan can be prepared while a 30-minute practice session is on. Both fields prefill from the current session; change them to plan a different race. The start time drives which stints count as night.

Built from the DRIVERS table: a stint is a tank of fuel — it runs until the usable fuel (tank less safety litres) is burnt at the driver's dry burn, and only the max stint time cuts it shorter; night stints (21:00–06:00) only go to night-capable drivers; double-stint drivers run two stints back-to-back; seat time is balanced across the crew. Regenerate after changing driver settings, or REPLAN to rebuild only the remainder around what has actually been driven (REPLAN always follows the live session clock, not the timeline above). Both need a live link to the pit wall — the plan is race state and lives there, so every station reads the same one — and they need a crew in the driver table and a race length. When something is missing they say which; they never just sit there.

Saved plans

No plans saved yet.

SAVE keeps the plan in the table below under a name. Saved plans live on the pit wall PC with the race state, so every station sees the same list and they survive restarts. LOAD makes a saved plan the active shared plan for this car — generate a plan for the real race, save it, run the short session, and load it back when the race starts.

The DRIVER column is the running order the stop card reads: GREEN's DRIVER line names whoever this table has down for the next stint. It works the other way round too — calling a driver by hand on the GREEN card moves them up to the next stint here and slides the order behind them one stint back, so nobody gains or loses a stint and every row after the stop still tells the truth about who gets in and when. CODE 60 and SAFETY CAR pins are for that stop alone and never touch the order. Anything the order then breaks — a night stint on a driver who does not drive at night, a double for someone who is not down for one, a drive-time limit — is called out above the table, on the row itself, and back on the GREEN card's DRIVER line.
